# تجويد القرآن التفاعلي — Tajwid Quran

**الموقع · Website · Webseite: https://tajwid-quran.pages.dev**

<div dir="rtl">

قراءة القرآن الكريم بأحكام التجويد ملوّنةً على الحروف نفسها، مع شرح كل حكم وأمثلته والاستماع إليه —
برواية حفص عن عاصم.

**التنزيل:** من صفحة [الإصدارات](../../releases/latest) — أحدث إصدار دائمًا:

- **ويندوز ١٠/١١:** `Tajwid-Quran-windows-setup.exe` (مثبّت) أو `Tajwid-Quran-windows-portable.zip` (دون تثبيت)
- **أندرويد ٧ أو أحدث:** `Tajwid-Quran-android.apk`

يعمل البرنامج دون إنترنت بالقرآن كاملًا؛ الصوت وحده يُحمَّل عند التشغيل.
مواضع التجويد مولَّدة آليًّا ولم يراجعها أهل العلم بعدُ.

</div>

---

Read the Qur'an with the tajwīd rules coloured on the letters themselves, with an explanation of every rule,
its examples and audio (Ḥafṣ ʿan ʿĀṣim).

**Download** from [Releases](../../releases/latest) (always the newest version):

| File | For |
|---|---|
| `Tajwid-Quran-windows-setup.exe` | Windows 10/11, installer |
| `Tajwid-Quran-windows-portable.zip` | Windows 10/11, no installation: unzip, start `Tajwid-Quran.exe` |
| `Tajwid-Quran-android.apk` | Android 7 or newer |

The whole Qur'an works offline; only the audio is loaded when you play it.
Windows shows “Windows protected your PC” on the first start because the app is not commercially signed:
*More info → Run anyway*. The tajwīd places are generated automatically and not yet reviewed by scholars.

This repository contains only the release files. Sources and licences: on the website under “البيانات القانونية” (https://tajwid-quran.pages.dev/#/legal).
